# AWS VPC Peering Lab Simulation

**Author:** Rohan

An interactive, browser-based simulation of AWS VPC Peering that demonstrates network connectivity between two Virtual Private Clouds (VPCs), route tables, security groups, and packet routing.

Built with React, TypeScript, Vite, and Tailwind CSS, this project provides a hands-on environment for exploring cloud networking concepts, testing connectivity, and understanding common routing and security issues.

**Note:** This is an educational simulation. It does not deploy real AWS resources or require an AWS account.
